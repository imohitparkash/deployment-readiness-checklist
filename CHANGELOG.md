# Changelog

All notable changes to this checklist are documented here.

## [1.0.0] - 2026-08-18

### Added
Initial release of the Deployment Readiness Checklist, covering 30 categories:

Project/Code Readiness, Dependency Management, Environment Configuration, Secrets & Credentials, Security, Authentication & Authorization, Database, API/Backend, Frontend, Testing, Error Handling, Logging, Monitoring/Observability, Performance, Accessibility, SEO, HTTPS/TLS, Domain & DNS, Hosting/Infrastructure, CI/CD, Containers, Cloud Configuration, Backups & Disaster Recovery, Privacy/Data Handling, Production Configuration, Deployment Process, Smoke Testing After Deployment, Rollback/Recovery, Documentation, and Post-Deployment Maintenance.

Every item is tagged with a priority (Critical / Recommended / Nice-to-have) and, where relevant, an applicability note for stack-specific or context-specific items (Docker, Cloud, marketing sites, etc.).

Includes `templates/.env.example` and `templates/production-notes.md` to support the checklist in practice.

- `deployment-checklist.pdf` — printable version generated from `CHECKLIST.md`.
